# Initializing the mkdoc project
Following the tutorial from [here](https://www.youtube.com/watch?v=xlABhbnNrfI).

```
# initialize venv
uv pip install mkdocs-material

# then run
mkdocs new .

# manually configure yaml

# then run 'mkdocs serve'
mkdocs serve

# and open browser

# to build
mkdocs build
```
